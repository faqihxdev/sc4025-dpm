# Product blueprint

Keep report-ready product work here. Create subfolders only when material exists.

Suggested sections:

- `discovery/`: problem framing, target users, jobs to be done, and insights.
- `strategy/`: value proposition, positioning, roadmap, and success metrics.
- `product/`: PRD, user stories, acceptance criteria, and MVP scope.
- `design/`: user flows, wireframes, prototypes, and usability findings.
- `go-to-market/`: launch approach, channels, pricing, and adoption plan.
- `governance/`: privacy, ethics, operational risks, and mitigations.
- `report/`: report outline, slide narrative, and final asset checklist.

Link claims to the supporting file in `research/`. Keep unresolved assumptions and
decisions visible instead of silently overwriting them.
