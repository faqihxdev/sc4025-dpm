# Functional MVP

Place the working prototype here after the team agrees on the selected problem,
main user flow, and technology stack.

Before implementation, update this file with:

- the chosen stack and why it fits the MVP;
- prerequisites and installation commands;
- configuration and example environment variables;
- development, test, build, and demo commands;
- the implemented flow and known limitations;
- which integrations are real, mocked, or represented with prepared demo data.

The MVP should validate the documented product decisions. It does not need to
rebuild the full Starbucks platform.
