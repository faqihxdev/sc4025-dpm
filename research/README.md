# Research evidence

Store user, market, competitor, and literature research here. Use one clear topic
per Markdown file and a descriptive kebab-case filename, for example:

```text
starbucks-singapore-feature-audit.md
group-order-user-interviews.md
shared-payment-literature-review.md
```

Each research file should identify:

1. the question or decision being investigated;
2. the method and sample, if people were involved;
3. sources with URLs or document names and access dates;
4. findings, including conflicting evidence;
5. implications for the product and remaining uncertainty.

Remove identifying participant details and never fabricate findings or citations.
