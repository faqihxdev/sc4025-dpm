# Validation and tests

Keep validation proportional to the MVP. Add automated tests for business rules
and critical software flows, and document manual or usability checks that cannot
be automated.

For each critical flow, record:

- the requirement or hypothesis being tested;
- setup and test data;
- expected and observed behaviour;
- pass/fail result and evidence;
- defects, limitations, or follow-up actions.

Do not record a test as passed unless it was actually run.
